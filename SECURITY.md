# Security policy

Please report security issues privately to hello@sinter-3d.com rather than in a
public issue.

CI rejects moderate-or-higher vulnerabilities in production dependencies with
`npm audit --omit=dev --audit-level=moderate`. If an advisory cannot be fixed
immediately, any temporary exception must be documented here with the advisory
identifier, affected package and version, exposure analysis, compensating
controls, owner, and removal date. There are currently no exceptions.
